# rust-pract

This repository contains Rust programming exercises and practice projects to learn and improve Rust development skills.

## Project Structure

Each project exercise is organized as a separate folders with their own `Cargo.toml`:

```
./
├── palindrome/
├── user_manager/
└── ...
```

## Running the Code

To run any of the project, go to the intended project folder, 

and then run with: 
```bash
cargo run
```

### Examples:

```bash
# Run longest palindrome project
cd palindrome/
cargo run
```
